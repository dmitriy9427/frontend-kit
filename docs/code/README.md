# Разбор кода: файл за файлом

[Учебник](../learn/00-start.md) объясняет **идеи**: модуль, реестр, шина, схема. Здесь —
**конкретный код**: самые важные файлы кита разобраны порциями по 5–20 строк, после каждой
порции — что она делает и зачем.

## Как устроена каждая страница

1. **Что это** — где в проекте работает файл и что увидит пользователь.
2. **Что делает** — по пунктам, человеческим языком.
3. **Как пользоваться** — пример вызова или разметки.
4. **Код по частям** — настоящий код с объяснением.
5. **Что будет, если…** — уберите строку и посмотрите, что сломается.
6. **Проверьте себя** — вопросы с ответами под спойлером.
