Шаблон для фриланс-проектов: общий **кит** (JS-модули, SCSS, React-хуки, формы, dev-инструменты)
и четыре **стартера**: вёрстка (Vite + HTML + JS), React, React + TypeScript, Astro (мультиязычные сайты).

## Документация рядом с кодом

- **README.md в каждой папке кита** — что внутри и как это менять.
- **Комментарий в начале каждого файла** — что это, зачем и какие баги в нём закрыты.
- **Тесты рядом с кодом** (`*.test.js`) — живые примеры использования.

## Главные принципы

1. **HTML говорит, что на странице.** `data-module="accordion"` — и блок ожил. Убрали блок —
   код не запустится. Компонент (`<x-card>`) ставит `data-module` сам.
2. **Всё про блок — в одной папке.** `src/components/card/`: разметка, стили, JS, тест.
   Новое регистрируется само — никаких списков, которые надо не забыть дописать.
3. **Каждый модуль убирает за собой.** `init(el, ctx) → { destroy }`. Поэтому модули работают
   и в многостраничной вёрстке, и в React, и с подгружаемым контентом.
4. **Один источник правды.** Брейкпоинты — в SCSS (JS читает их оттуда), правила формы — в схеме,
   версии пакетов — в package.json шаблона.
5. **Ошибка должна быть понятной.** Опечатка в имени модуля, цвета, слоя z-index, брейкпоинта,
   схемы — сообщение по-русски с подсказкой, а не молчаливо сломанная страница.
6. **Dev-инструменты не попадают в прод** — и это проверяется при сборке.
