# src/modules — модули проекта без своей разметки

Модуль — поведение, которое вешается на уже существующую разметку через
`data-module="имя"`. Каждая папка `src/modules/<имя>/index.js` регистрируется
**сама** (см. `src/main.js`, `modulesFromGlob`) — в реестр ничего дописывать не нужно.

Когда модуль, а когда компонент:

|             | Модуль (`src/modules/`)              | Компонент (`src/components/`)              |
| ----------- | ------------------------------------ | ------------------------------------------ |
| Разметка    | чужая: пишется на странице или в CMS | своя: `<x-имя>` вставляет готовый HTML     |
| data-module | пишете сами                          | ставится автоматически, если есть `имя.js` |
| Пример      | «копировать в буфер» на любой кнопке | карточка, калькулятор, FAQ                 |

Создать: `npm run new -- module имя`. Пример — `hello/` (модуль + тест).
Подробно — [docs/modules.md](../../docs/modules.md#свой-модуль).
