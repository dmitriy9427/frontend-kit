# src/plugins — плагины приложения

Код, который нужен **всему сайту один раз** (а не конкретному блоку): аналитика,
сбор ошибок, настройка внешних ссылок, подписки на события шины.

- Каждый файл подключается **сам** (`src/main.js` → `pluginsFromGlob`), порядок —
  по имени файла: `01-…`, `02-…`.
- Запускается **до** модулей — к их старту настройки и подписки уже готовы.
- Получает `{ ctx, modules }` — ту же шину и доступ к модулям, что и модули.
- Может вернуть функцию уборки.

```js
// src/plugins/03-cookie-banner.js
export default function cookieBanner({ ctx }) {
  …
  return () => { /* уборка */ }
}
```

Плагин или модуль? Модуль — поведение **блока** на странице (`data-module`).
Плагин — поведение **сайта целиком**. GSAP-плагины (SplitText и т. п.) регистрируются
не здесь, а в `src/lib/gsap.js` — модули импортируют GSAP оттуда.
