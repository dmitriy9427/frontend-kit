# Стартер: вёрстка (Vite + HTML + JS)

| Путь                                                    | Что                                                              |
| ------------------------------------------------------- | ---------------------------------------------------------------- |
| `index.html`, `ui-kit.html`, `404.html`, `privacy.html` | страницы; новая `.html` в корне попадает в сборку сама           |
| `partials/`                                             | head, header, footer, модалка, согласие на обработку данных      |
| `src/main.js`                                           | стили → схемы форм → запуск модулей → dev-панель (только dev)    |
| `src/modules/`                                          | модули проекта + реестр `index.js` (пример — `hello/`)           |
| `src/forms/schemas.js`                                  | схемы форм (`data-form-schema="…"`)                              |
| `src/styles/`                                           | `_abstracts.scss` — настройки, `main.scss` — порядок подключения |
| `mocks/`                                                | фейковый API для dev                                             |
| `public/`                                               | favicon, robots.txt — копируются как есть                        |

**ui-kit.html** — живой каталог всех компонентов: показывать заказчику и проверять после правок.
