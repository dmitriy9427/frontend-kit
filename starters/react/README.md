# Стартер: React (Vite + React Router)

| Путь                   | Что                                                                               |
| ---------------------- | --------------------------------------------------------------------------------- |
| `src/main.jsx`         | StrictMode, KitProvider, роутер, dev-панель (только dev)                          |
| `src/App.jsx`          | маршруты, сброс прокрутки при смене страницы                                      |
| `src/pages/`           | страницы (редкие грузятся лениво)                                                 |
| `src/components/`      | Header, Footer, Accordion, Slider, CallbackDialog — модули кита через `useModule` |
| `src/forms/schemas.js` | схемы форм (объявлены вне компонентов)                                            |
| `src/styles/`          | как в vanilla                                                                     |
| `mocks/`               | фейковый API                                                                      |

Руководство — [docs/react.md](../../docs/react.md).
