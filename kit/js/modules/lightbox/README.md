# lightbox

Фото на весь экран с Flip-анимацией (из своей карточки в центр и обратно).

|                 |                                                                               |
| --------------- | ----------------------------------------------------------------------------- |
| Подключение     | `data-module="lightbox"`                                                      |
| Настройки       | — (подписи: data-lightbox-title/meta/credit; большое фото: data-lightbox-src) |
| API (экземпляр) | open(img, info, { group, getInfo }), close(), next(), prev(), current, isOpen |
| События         | —                                                                             |

**Что учтено:** Тот же элемент, а не копия; блокировка прокрутки; Esc и фон закрывают; фокус возвращается;
галерея — стрелки, ← →, свайп, счётчик; миниатюра в сетке и полный размер в окне.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#lightbox),
подробности и «почему так» — комментарий в начале `index.js`. Живой пример — `starters/vanilla/effects.html`.
