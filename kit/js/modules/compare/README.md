# compare

Сравнение «до / после» со шторкой.

|                 |                                                                       |
| --------------- | --------------------------------------------------------------------- |
| Подключение     | `data-module="compare"`; внутри две картинки и `<input type="range">` |
| API (экземпляр) | value, set                                                            |
| События         | compare:change                                                        |
| Стили           | `kit/scss/components/_compare.scss`, переменные `--compare-*`         |

**Что учтено:** шторка — настоящий ползунок: клавиатура, палец, мышь и скринридер работают сами; вертикальная прокрутка страницы пальцем поверх блока.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#compare),
подробности и «почему так» — комментарий в начале `index.js`.
