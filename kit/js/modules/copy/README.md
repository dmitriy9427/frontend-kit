# copy

Копирование в буфер обмена по клику: промокод, ссылка, реквизиты.

|                 |                                                                      |
| --------------- | -------------------------------------------------------------------- |
| Подключение     | `data-module="copy"` на обёртке (или `<body>`), кнопки — `data-copy` |
| Атрибуты кнопки | data-copy, data-copy-target, data-copy-message, data-copy-toast      |
| Из JS           | `copyText(text)`                                                     |
| События         | copy:done, copy:error                                                |

**Что учтено:** нет `navigator.clipboard` (http, старые браузеры) — запасной путь; браузер запретил — уведомление об ошибке, а не тишина; класс `is-copied` на 2 с для смены иконки.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#copy),
подробности и «почему так» — комментарий в начале `index.js`.
