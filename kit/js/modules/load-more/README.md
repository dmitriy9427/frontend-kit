# load-more

«Показать ещё»: догрузка следующей страницы списка без перезагрузки.

|                 |                                                                                       |
| --------------- | ------------------------------------------------------------------------------------- |
| Подключение     | `data-module="load-more"`; внутри `[data-load-more-list]`, `a[data-load-more-button]` |
| Настройки       | auto, margin                                                                          |
| API (экземпляр) | load, page, complete                                                                  |
| События         | load-more:loaded, load-more:error                                                     |

**Что учтено:** кнопка — обычная ссылка на следующую страницу (работает без JS, бэкенд менять не нужно); ответ — HTML-страница или JSON `{ html, next }`; двойной клик; фокус на первый новый элемент; ошибка сети — можно повторить; `auto` — бесконечная лента.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#load-more),
подробности и «почему так» — комментарий в начале `index.js`.
