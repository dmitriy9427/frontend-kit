# rating

Рейтинг звёздами: показ оценки (в т.ч. дробной) и выбор оценки в форме.

|                 |                                                                           |
| --------------- | ------------------------------------------------------------------------- |
| Подключение     | `data-module="rating"`                                                    |
| Настройки       | value, max (показ), clearable (выбор)                                     |
| API (экземпляр) | value, set, reset                                                         |
| События         | rating:change (на элементе и в шине)                                      |
| Стили           | `kit/scss/components/_rating.scss`, переменные `--rating-size/color/icon` |

**Что учтено:** выбор — настоящие radio (стрелки, FormData, схема формы, работает без JS);
подписи звёзд и оценки для скринридера на языке страницы; повторный клик снимает оценку
(clearable), а «клик» с клавиатуры — нет; set/reset из кода шлют change; сброс формы.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#rating),
подробности и «почему так» — комментарий в начале `index.js`.
