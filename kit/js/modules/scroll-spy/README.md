# scroll-spy

Подсветка пункта меню для секции, которая сейчас на экране.

|                 |                                                       |
| --------------- | ----------------------------------------------------- |
| Подключение     | `data-module="scroll-spy"` на блоке со ссылками `#id` |
| Настройки       | offset, activeClass                                   |
| API (экземпляр) | update, active                                        |
| События         | scroll-spy:change                                     |

**Что учтено:** секции выше экрана и короче экрана; последняя секция у конца страницы; учёт высоты шапки (`--header-height`); ссылки на другие страницы не трогаются.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#scroll-spy),
подробности и «почему так» — комментарий в начале `index.js`.
