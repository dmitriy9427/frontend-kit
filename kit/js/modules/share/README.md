# share

«Поделиться»: системное окно на телефоне и ссылки на соцсети.

|             |                                                                         |
| ----------- | ----------------------------------------------------------------------- |
| Подключение | `data-module="share"`; внутри `[data-share-native]`, `a[data-share-to]` |
| Настройки   | url, title, text                                                        |
| Сети        | telegram, vk, whatsapp, ok, viber, x, facebook, linkedin, email         |
| Из JS       | `shareUrl(network, { url, title, text })`                               |
| События     | share:done                                                              |

**Что учтено:** обычные ссылки без скриптов соцсетей; канонический адрес страницы; нет Web Share API — копирование ссылки с уведомлением; отмена системного окна — не ошибка.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#share),
подробности и «почему так» — комментарий в начале `index.js`.
