# countdown

Обратный отсчёт до даты или «личный» таймер от первого визита.

|                 |                                                           |
| --------------- | --------------------------------------------------------- |
| Подключение     | `data-module="countdown"` + `data-countdown-to="…+03:00"` |
| Настройки       | to, minutes, key, pad                                     |
| API (экземпляр) | left, ended                                               |
| События         | countdown:end                                             |

**Что учтено:** часовой пояс (предупреждение, если не указан); время считается от часов, а не вычитанием секунды — фоновая вкладка не «отстаёт»; склонение подписей на языке страницы; role="timer"; личный таймер переживает перезагрузку.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#countdown),
подробности и «почему так» — комментарий в начале `index.js`.
