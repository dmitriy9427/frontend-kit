# reveal

Появление элементов [data-reveal] при прокрутке.

|                 |                                |
| --------------- | ------------------------------ |
| Подключение     | `data-module="reveal"`         |
| Настройки       | start, duration, stagger, once |
| API (экземпляр) | —                              |
| События         | —                              |

**Что учтено:** Без «вспышки»: CSS прячет только при JS; страховка 3 с; reduced motion — без анимации.

Разметка и примеры — [docs/modules.md](../../../../docs/modules.md#reveal),
подробности и «почему так» — комментарий в начале `index.js`.
